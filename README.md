# POWER-BI-Project-on-UPI-Transaction-Analysis
UPI Transactions Analysis Dashboard

📌 Project Overview

This project is an interactive Power BI dashboard developed to analyze UPI (Unified Payments Interface) transactions. The dashboard provides insights into transaction performance, user behavior, payment methods, banks, devices, and transaction trends. It enables stakeholders to monitor key metrics, identify patterns, and make data-driven decisions.

🎯 Objectives

Analyze overall UPI transaction performance.
Track successful and failed transactions.
Understand customer payment behavior.
Identify top-performing banks and payment methods.
Monitor transaction trends over time.
Compare transaction values across different dimensions.

🛠️ Tools & Technologies
